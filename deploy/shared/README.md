# تشغيل همّة على استضافة Hostinger المشتركة (Premium)

هذه الطريقة للاستضافة المشتركة (hPanel). إذا كان عندك سيرفر VPS فاستعمل [الطريقة الأخرى](../README.md).

## ١. من لوحة hPanel (مرة واحدة)

1. **Advanced ← PHP Configuration**: اختر **PHP 8.3** أو أحدث واحفظ.
2. **Databases ← Management**: أنشئ قاعدة بيانات (الاسم والمستخدم يبدآن تلقائياً بـ `u..._`). احفظ **اسم القاعدة** و**اسم المستخدم** و**كلمة السر**.
3. اختياري، لإرسال روابط تغيير كلمة السر: **Emails** ← أنشئ بريداً مثل `noreply@himma.com` واحفظ كلمة سره.
4. **Advanced ← SSH Access**: تأكد أنه **Active**، واحفظ العنوان (IP) والمنفذ (Port) واسم المستخدم. إذا لم تكن عندك كلمة سر لـ SSH فاضبطها من نفس الصفحة.

## ٢. ادخل إلى الاستضافة من جهازك

من ويندوز افتح **PowerShell** واكتب (بقيمك من صفحة SSH Access):

</div>

```
ssh -p 65002 u250057334@46.202.158.163
```

<div dir="rtl">

اكتب `yes` عند السؤال الأول، ثم كلمة سر SSH (لا تظهر الأحرف أثناء الكتابة، وهذا طبيعي).

## ٣. ركّب المنصة

الصق السطرين:

</div>

```
git clone https://github.com/Ameen041/Gym-Management-System.git ~/himma
bash ~/himma/deploy/shared/install.sh
```

<div dir="rtl">

سيسألك عن:

1. **الدومين**: يقترحه وحده (مثل `himma.com`)، اضغط Enter.
2. **قاعدة البيانات**: الاسم والمستخدم وكلمة السر من الخطوة ١. يجرّبها فوراً، وإذا كان فيها خطأ يسألك من جديد.
3. **إيميل الأدمن وكلمة سره** (10 أحرف على الأقل، مرتين).
4. **البريد**: البريد الذي أنشأته وكلمة سره، أو Enter لتتخطاه الآن.

بعدها ينزّل المكتبات، ويجهّز قاعدة البيانات، ويوجّه الدومين إلى المنصة. ما كان في `public_html` يبقى محفوظاً باسم `public_html.before-himma`. يأخذ ذلك بضع دقائق، وفي النهاية يكتب **Himma is installed**.

## ٤. آخر خطوتين في hPanel

1. **المهمة كل دقيقة** (التذكيرات والنسخة الاحتياطية الليلية): إذا كتب لك التركيب *The every-minute task is set* فهي جاهزة. وإلا افتح **Advanced ← Cron Jobs**، واختر **Custom**، والصق الأمر الذي طبعه لك التركيب، واختر **كل دقيقة** (Every minute).
2. **HTTPS**: من **Security ← SSL** تأكد أن الشهادة مفعّلة (مجانية)، وشغّل **Force HTTPS**.

ثم افتح `https://himma.com`، وسجّل الدخول بإيميل الأدمن، وافتح **النظام**: يجب أن تكون الأسطر خضراء. سطر النسخة الاحتياطية يخضرّ بعد أول ليلة، أو اضغط «نسخ احتياطي الآن».

## الأوامر اليومية

افتح جلسة SSH جديدة (أو اكتب `source ~/.bashrc` مرة واحدة) ثم:

| الأمر | ماذا يفعل |
|---|---|
| `himma update` | يجلب آخر نسخة من GitHub (فرع master). يظهر للزوار «نعود خلال دقيقة» حتى ينتهي. الإعدادات والبيانات تبقى |
| `himma backup` | نسخة احتياطية الآن، ويطبع لك أمر `scp` الجاهز لتنزيلها على جهازك |
| `himma logs` | آخر الأخطاء إن وجدت |
| `himma status` | هل الموقع يعمل، ومتى تعمل المهام |

إذا لم يعمل أمر `himma` فاكتبه كاملاً: `bash ~/himma/deploy/shared/himma update`

**التحديث:** ادمج التعديلات على GitHub أولاً، ثم ادخل بـ SSH وشغّل `himma update`.

## النسخ الاحتياطية

- المنصة تأخذ نسخة كل ليلة وتحتفظ بآخر 14 نسخة، وHostinger تأخذ نسخة أسبوعية من الاستضافة كلها.
- مع ذلك **نزّل نسخة كل أسبوع إلى جهازك**: من صفحة **النظام** في لوحة الأدمن، أو بالأمر الذي يطبعه `himma backup`.

## تعديل الإعدادات لاحقاً

الإعدادات وكلمات السر في `~/himma/.env` (لا تُرفع إلى GitHub). مثلاً لإضافة البريد لاحقاً:

</div>

```
nano ~/himma/.env
```

<div dir="rtl">

عدّل أسطر `MAIL_` (اترك علامتي ' حول القيم)، احفظ بـ `Ctrl+O` ثم Enter، واخرج بـ `Ctrl+X`، ثم شغّل `himma update`.

## إذا صار شيء

- **الموقع يعرض صفحة Hostinger القديمة:** انتظر دقيقة وحدّث الصفحة، ثم شغّل `himma status`.
- **خطأ 500:** `himma logs` وأرسل آخر الأسطر لمن يساعدك.
- **PHP 8.3 was not found:** اختر PHP 8.3 من **PHP Configuration** وشغّل التركيب من جديد.
- **المنصة بقيت على «نعود خلال دقيقة»:** `himma artisan up`.
- **تريد الانتقال إلى VPS لاحقاً:** خذ نسخة احتياطية من صفحة النظام، وركّب [طريقة الـ VPS](../README.md)، ثم استرجع النسخة بـ `himma artisan app:restore`.
